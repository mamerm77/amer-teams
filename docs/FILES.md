# Shared files with versions

Chat menu → **Files and media**: every file shared in the chat, built on this device from its end-to-end encrypted history (about the last 1,500 events).

- **Grouped** into Documents, Images, Audio and video, and Other, with a count on each tab and a name filter.
- **Versions:** a file shared again under the same name becomes a new version. The list shows the latest ("v3 · Sara · date · size") and expands to every earlier version. Any version opens in the on-device preview with its comments (FILE_PREVIEWS.md).

## Open gaps
- Versions are matched by file name, so renaming a file starts a new history.
- There's no compare-versions view, and no upload button on this screen: share the file in the chat to add a version.
