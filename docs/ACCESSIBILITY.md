# Accessibility

Settings → Security → **Accessibility**. These settings add to the operating system's own (screen reader, system text size, system high contrast) and work the same on every platform.

- **Text size:** 85% to 200%, multiplying the system size.
- **High contrast:** Material high-contrast colour schemes (light and dark), solid dividers, and 2-pixel input borders and focus outlines.
- **Bold text** and **reduce motion** (no animated transitions; floating reactions in calls are suppressed).
- **Captions on when I join a call** (speech is transcribed on the device). Translated captions are available too.
- **Keyboard shortcuts in calls:** Ctrl+D mute, Ctrl+E camera, Ctrl+Shift+H raise hand, Ctrl+Shift+C captions, Ctrl+Shift+L leave.
- **Screen readers:** call buttons speak their label once (the visible caption isn't read twice). Mute, camera, a raised hand and the start of a recording are announced.

## Open gaps
- Not yet audited with TalkBack, VoiceOver or NVDA by a person who uses them daily. Some older screens still rely on icon tooltips only.
- No WCAG 2.2 conformance report yet. Colour contrast in the default theme hasn't been measured screen by screen.
- Sign-language interpreter pinning (keeping a chosen video always visible) isn't built.
