# Chatting with Amer, the AI assistant

Amer is a participant you can message, like Copilot chat in Teams.
- **Direct chat:** Amer tab → **Chat with Amer**. Amer replies to every message, with the recent conversation as context, so follow-up questions work.
- **Group chat:** add Amer to the group, then **@mention Amer**. It stays quiet otherwise, and answers as a reply to your message.
- It asks the same agents as the Amer tab: the Router picks Summariser, Translator, Scheduler, Minutes or Amer.

## Privacy and control
| Rule | How |
|---|---|
| Amer reads only chats it has been added to | It is a normal end-to-end encrypted member (`@amer`); the server sees only ciphertext, including Amer's replies |
| Users are told | The first message in each chat says questions and recent messages go to the AI service |
| Sensitive chats never reach the AI | Chat info → **Sensitivity label**: Confidential or Restricted. Guardian blocks those chats. Emirates IDs, card numbers and IBANs are redacted from everything else. |
| Administrators stay in control | Control → Amer on/off pauses the chat assistant too. Every question is audited against the user who asked. |
| Only the bot can use its endpoint | Shared secret `AMER_BOT_SECRET` (generated by the setup scripts) |

## Set-up
The setup scripts (`setup-local.ps1`, `create-admin.sh`) create the `amer` account, `AMER_BOT_PASSWORD` and
`AMER_BOT_SECRET`, and start the `amer-bot` service. The answers come from the model configured in `.env`
(`ANTHROPIC_API_KEY`, `LLM_MODEL`). Without a key, Amer says that it is not set up yet.

## Verified (tests/amer_bot_test.py, live, 12/12)
- **Joining and encryption:**
  - joins direct chats
  - gives the privacy notice, then the answer
  - replies are encrypted on the server
- **Group chats:** quiet unless @mentioned, then answers as a reply.
- **Safety and control:**
  - a Confidential chat is blocked by Guardian
  - the admin pause works
  - each question is audited for the asker
  - a forged bot secret is refused
- **Not set up:** without a provider key, it says so clearly.
